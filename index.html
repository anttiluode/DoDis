The actual experiment

For each bird never used in the memory or graph training, hide half its 64 octave/tile residues. Retrieve candidate patches using the visible pieces only. Discrete coordinate descent compares identical candidate pools and starts under four energies: remembered content plus boundary smoothness; plus learned binding; a shuffled-binding control; and plus an optional teacher-distilled purpose term.

The key measurement is image reconstruction error against the withheld original. CNN margin is a separate outcome, measured after settling. A higher bird score accompanied by a worse image is the adversarial pull we want to expose—not a successful repair.

The score called “pixel MSE” measures the reconstructed whole image, which differs from truth only through missing multiscale residues; it is not a conventional contiguous missing-pixel hole. All models in this experiment operate over the same 64-piece Sihti decomposition. The optional CNN surrogate is trained across multiple images; it is not v3’s one-photo switch polynomial.

Research instrument, not a production image-completion model. Inspect the source and locked protocol. The viewer reads the measured v1 docs/receipt.json and, when published, the independent v2 docs/receipt_v2.json. Mouseover or graph confidence alone cannot supply missing image content.
